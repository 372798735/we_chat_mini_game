## 组件说明

### 1. 顶部工具栏

- **新建任务按钮**: 快速创建新任务
- **开始计时按钮**: 快速启动专注计时
- **搜索框**: 搜索任务功能
- **通知图标**: 显示系统通知数量
- **设置图标**: 进入设置页面

### 2. 左侧导航栏

- **任务管理**: 默认选中，显示任务相关功能
- **统计分析**: 显示数据和图表
- **设置**: 应用配置选项
- 导航项支持图标+文字展示

### 3. 主内容区域

- **今日任务概览**: 显示统计数据
  - 待完成任务数
  - 已完成任务数
  - 总任务数
  - 完成率进度条

- **今日任务列表**: 显示今日所有任务
  - 任务标题
  - 预计时长
  - 完成状态（复选框）
  - 优先级标识（颜色或图标）

### 4. 底部状态栏

- **今日专注时间**: 累计专注时长
- **完成率**: 今日任务完成百分比
- **当前时间**: 实时时间显示
- **托盘按钮**: 最小化到系统托盘

## 交互设计

### 状态变化

1. **导航切换**: 点击左侧导航切换主内容区域
2. **任务操作**:
   - 点击复选框标记完成
   - 点击任务查看详情
   - 右键显示操作菜单
3. **快捷操作**: 顶部按钮提供常用功能快速访问

### 响应式设计

- **最小窗口尺寸**: 800x600
- **可调整布局**: 导航栏可折叠
- **自适应**: 内容区域根据窗口大小调整

### 视觉层次

- **主次分明**: 重要信息突出显示
- **状态可视化**: 使用颜色区分任务状态
- **简洁清晰**: 避免信息过载
