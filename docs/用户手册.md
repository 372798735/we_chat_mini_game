## 快速开始

### 1. 启动应用

#### Windows系统
```bash
# 双击运行
start.bat

# 或使用命令行
cd C:\tomato-todo
start.bat
```

#### Linux/Mac系统
```bash
# 运行启动脚本
./start.sh

# 或使用 systemd
systemctl start tomato-todo
```

### 2. 首次使用

1. **访问应用**: 打开浏览器访问 `http://localhost`
2. **创建第一个任务**:
   - 点击"新建任务"按钮
   - 填写任务信息
   - 设置预计时长
   - 保存任务
3. **开始专注**:
   - 点击任务卡片上的"开始"按钮
   - 进入番茄钟计时界面
   - 专注完成您的任务

## 任务管理

### 创建任务

1. **方式一：快速创建**
   - 点击右上角"创建任务"按钮
   - 或使用快捷键 `Ctrl + N`

2. **方式二：从任务列表创建**
   - 进入任务管理页面
   - 点击"新建任务"

3. **填写任务信息**
   ```
   任务标题: [必填] 清晰描述任务内容
   任务描述: [可选] 任务的详细说明
   预计时长: [必填] 完成任务需要的时间（分钟）
   优先级: [必填] 高/中/低
   截止时间: [可选] 任务的最后完成期限
   提醒时间: [可选] 任务提醒时间
   分类: [可选] 任务所属分类
   标签: [可选] 用于任务的标签分类
   ```

### 任务状态管理

#### 状态流转
```
待处理 → 进行中 → 已完成
   ↓         ↓
已暂停    已取消
```

#### 状态操作

1. **开始任务**
   - 点击任务卡片的"开始"按钮
   - 自动进入番茄钟计时界面
   - 任务状态变为"进行中"

2. **暂停任务**
   - 在计时界面点击"暂停"
   - 或在任务列表中点击"暂停"
   - 任务状态变为"已暂停"

3. **完成任务**
   - 在计时完成后点击"完成"
   - 或在任务列表中点击"完成"
   - 自动弹出总结表单

4. **编辑任务**
   - 点击任务卡片右侧菜单
   - 选择"编辑任务"
   - 修改任务信息后保存

5. **删除任务**
   - 点击任务卡片右侧菜单
   - 选择"删除任务"
   - 确认删除操作

### 任务搜索和筛选

#### 搜索功能
- **关键词搜索**: 在搜索框输入任务标题或描述
- **实时搜索**: 输入时实时显示匹配结果
- **历史搜索**: 保存最近的搜索记录

#### 筛选选项
- **按状态**: 待处理、进行中、已完成、已暂停、已取消
- **按优先级**: 高、中、低
- **按分类**: 工作、学习、生活等
- **按时间**: 今日任务、逾期任务
- **按标签**: 自定义标签筛选

#### 排序功能
- **创建时间**: 最新/最旧
- **截止时间**: 最近/最远
- **优先级**: 高到低/低到高
- **完成率**: 高到低/低到高

## 番茄钟计时

### 番茄工作法原理

番茄工作法是一种时间管理方法：
1. **25分钟专注工作**
2. **5分钟短休息**
3. **重复4次后，进行15-30分钟长休息**

### 使用步骤

#### 1. 开始计时
```
选择任务 → 设置时长 → 点击"开始" → 专注工作
```

#### 2. 计时界面
```
┌─────────────────────────────────────────┐
│              🍅 专注工作                  │
│                                         │
│        ⏱️  25:00                      │
│        ████████████ 50%                │
│                                         │
│  [暂停] [停止] [跳过]                   │
└─────────────────────────────────────────┘
```

#### 3. 计时操作
- **暂停**: 临时中断计时
- **停止**: 完全结束当前计时
- **跳过**: 提前结束当前阶段
- **调整**: 修改计时时长（设置中）

#### 4. 休息时间
```
短休息模式: ☕ 5分钟
长休息模式: 🏖️ 15-30分钟

[继续工作] [跳过休息]
```

### 计时器设置

#### 基础设置
- **工作时长**: 15-60分钟（默认25分钟）
- **短休息时长**: 1-10分钟（默认5分钟）
- **长休息时长**: 10-30分钟（默认15分钟）
- **长休息间隔**: 2-8个番茄钟（默认4个）

#### 高级设置
- **自动开始**: 休息后自动开始工作
- **自动休息**: 工作后自动开始休息
- **声音提醒**: 计时结束时播放提示音
- **桌面通知**: 显示系统通知
- **专注模式**: 隐藏干扰元素

### 计时统计

#### 今日统计
- ✅ 完成番茄数
- ⏱️ 专注时长
- 🔄 连续天数
- 📊 完成率

#### 历史记录
- 📅 每日番茄钟记录
- 📈 专注时长趋势
- 🏆 最佳记录
- 📋 任务完成情况

## 任务总结

### 为什么需要总结？

任务总结帮助您：
- 📝 记录任务完成情况
- 💭 反思工作过程
- 📈 追踪个人成长
- 🎯 改进工作效率

### 创建总结

#### 触发时机
1. **任务完成时**自动弹出总结表单
2. **手动创建**: 从任务列表选择已完成任务
3. **批量总结**: 在统计分析页面创建

#### 总结内容

##### 1. 完成度评价 ⭐
```
优秀: 超出预期，完成得很出色
良好: 达到预期，完成得不错
一般: 基本达到预期
较差: 未达到预期，需要改进
```

##### 2. 任务感受 😊
```
心情状态: 非常愉快、愉快、一般、不愉快、很不愉快
```

##### 3. 难度感受 ⭐
```
难度评级: 很容易、容易、适中、困难、很困难
```

##### 4. 专注程度 🎯
```
专注度: 非常专注、专注、一般、容易分心、很分心
```

##### 5. 文字描述
```
- 任务完成过程中的收获
- 遇到的困难和解决方法
- 下次改进的建议
- 相关的知识和技能
```

##### 6. 标签分类
```
示例: #学习 #工作 #成长 #技术 #沟通
```

### 查看总结

#### 总结列表
- 按时间排序显示所有总结
- 支持按评价、心情、难度筛选
- 提供搜索功能快速查找

#### 统计分析
- **评价分布**: 各评价等级的数量占比
- **心情趋势**: 心情状态的变化趋势
- **难度适应性**: 难度感受与完成率的关系
- **专注度变化**: 专注程度的改进情况

#### 成长轨迹
- **技能提升**: 记录获得的新技能
- **经验积累**: 重要的工作经验和心得
- **个人成长**: 体现个人成长的记录

## 常见问题

### 使用问题

#### Q: 忘记设置提醒，如何补加提醒？
A: 进入任务编辑页面，重新设置提醒时间即可。

#### Q: 计时器意外停止，数据会丢失吗？
A: 不会丢失，系统会自动保存计时进度。重新启动后可以继续。

#### Q: 如何批量编辑多个任务？
A: 在任务列表中勾选多个任务，使用批量操作功能。

#### Q: 统计数据不准确怎么办？
A: 在设置中选择"重新计算统计数据"。

#### Q: 如何备份和恢复数据？
A: 在设置中配置自动备份，或手动导出数据文件。

### 技术问题

#### Q: 应用无法启动
A: 检查Java环境是否正常，查看日志文件定位具体问题。

#### Q: 页面加载缓慢
A: 清理浏览器缓存，检查网络连接，或调整数据加载设置。

#### Q: 数据同步失败
A: 检查网络连接，确认云服务配置，尝试手动同步。

#### Q: 提醒通知不显示
A: 检查系统通知权限设置，确认应用通知权限已开启。

### 性能问题

#### Q: 内存占用过高
A: 调整数据缓存大小，定期清理过期数据。

#### Q: 数据库响应慢
A: 检查数据库状态，考虑数据清理或重建索引。
