# 番茄闹钟待办清单软件需求文档

## 1. 产品概述

### 1.1 产品定位

一款基于番茄工作法的时间管理Windows桌面软件，帮助用户高效管理每日任务，通过专注时间与休息时间的合理分配，提升工作效率和生活品质。

### 1.2 目标用户

- 需要时间管理的学生群体
- 希望提高工作效率的职场人士
- 希望养成良好工作习惯的自媒体创作者
- 其他需要专注时间管理的用户群体

### 1.3 产品价值

- 简洁易用的任务管理体验
- 科学的时间分配方法
- 可视化的任务进度追踪
- 个人成长数据记录
- 桌面端便捷操作，无需切换应用

## 2. 核心功能需求

### 2.1 任务管理模块

#### 2.1.1 创建任务

**功能描述**：用户可以创建新的待办任务

**需求细节**：

- 任务标题（必填，最多50字符）
- 任务预计时长（必填，支持5-120分钟，默认25分钟）
- 任务备注（选填，最多200字符）
- 任务分类（选填，工作/学习/生活/自定义）
- 任务优先级（选填，高/中/低）
- 设置截止日期（选填）

#### 2.1.2 任务列表展示

**功能描述**：以列表形式展示所有任务

**需求细节**：

- 按创建时间倒序排列
- 支持按优先级排序
- 支持按分类筛选
- 显示任务标题、预计时长、状态
- 今日任务标识
- 已完成任务灰显

#### 2.1.3 任务编辑

**功能描述**：修改已创建的任务信息

**需求细节**：

- 所有创建时可填写的字段均可修改
- 保留修改历史
- 进行中的任务不可修改时长

#### 2.1.4 任务删除

**功能描述**：删除不需要的任务

**需求细节**：

- 支持单个删除
- 已完成的任务可批量删除
- 删除前需要确认
- 进行中的任务不可删除

### 2.2 专注计时模块

#### 2.2.1 计时启动

**功能描述**：点击任务开始专注计时

**需求细节**：

- 显示任务标题和预计时长
- 倒计时显示醒目，大字体呈现剩余时间
- 提供暂停/继续功能
- 提供提前结束功能
- 倒计时结束时震动提醒

#### 2.2.2 计时页面设计

**功能描述**：专注时的视觉体验

**需求细节**：

- 全屏显示剩余时间
- 圆形进度条展示完成进度
- 任务标题显示在顶部
- 背景颜色根据时间进度渐变
- 最小化干扰，隐藏其他无关信息
- 支持翻转手机翻转暂停（可选）

#### 2.2.3 休息提醒

**功能描述**：完成专注后的休息提醒

**需求细节**：

- 短暂休息提示（5分钟）
- 长时间休息提示（15分钟，每4个番茄钟后）
- 休息时间计时功能
- 下一个任务快速开始按钮

### 2.3 任务总结模块

#### 2.3.1 完成总结

**功能描述**：任务完成后的总结记录

**需求细节**：

- 完成度评价（很好/好/一般/需要改进）
- 文字总结（最多500字符）
- 标签添加（如：#专注 #高效）
- 实际用时记录
- 总结内容可后续修改

#### 2.3.2 查看历史

**功能描述**：查看任务完成记录

**需求细节**：

- 按日期分组显示
- 显示任务完成情况
- 查看总结内容
- 统计功能（完成率、总时长等）

### 2.4 统计分析模块

#### 2.4.1 今日统计

**功能描述**：展示今日任务完成情况

**需求细节**：

- 完成任务数/总任务数
- 总专注时长
- 平均每项任务用时
- 任务完成率

#### 2.4.2 历史统计

**功能描述**：展示历史数据趋势

**需求细节**：

- 最近7天/30天的任务完成趋势图
- 每日专注时长对比
- 任务分类统计
- 最佳表现时段分析

## 3. 界面设计需求

### 3.1 窗口管理

- 可调整窗口大小，支持最小尺寸限制（如800x600）
- 支持窗口最大化、最小化、还原操作
- 窗口位置和大小记忆功能，下次启动恢复上次状态
- 支持窗口置顶功能
- 系统托盘图标，支持托盘最小化

### 3.2 主界面布局

- 左侧导航栏：任务管理、统计分析、设置
- 中间内容区：动态展示当前选中功能
- 顶部工具栏：快速操作按钮（新建任务、开始计时等）
- 底部状态栏：显示今日统计、当前时间

### 3.3 任务列表界面

- 任务列表视图，支持列表和卡片两种显示模式
- 右键菜单：编辑、删除、标记完成、设置优先级
- 拖拽排序功能
- 批量操作功能（全选、批量删除、批量标记）

### 3.4 专注计时界面

- 紧凑模式和全屏模式切换
- 圆形进度条+大字体倒计时显示
- 控制按钮：开始、暂停、继续、结束
- 显示当前任务信息
- 背景毛玻璃效果，减少干扰

### 3.5 统计图表界面

- 折线图、柱状图、饼图等多种图表展示
- 时间范围选择器（今天、本周、本月、自定义）
- 数据导出功能（CSV、Excel格式）
- 图表交互：鼠标悬停显示详细数据

### 3.6 设置界面

- 选项卡式布局：常规、提醒、外观、数据
- 实时预览设置效果
- 一键恢复默认设置
- 导入/导出配置功能

## 4. 用户体验需求

### 4.1 视觉设计

- 整体风格简约清新
- 颜色搭配舒适护眼
- 字体大小适中
- 图标简洁易懂

### 4.2 交互体验

- 操作流程简洁
- 反馈及时明确
- 键盘快捷键支持
- 鼠标悬停提示
- 拖拽操作支持
- 错误提示友好

### 4.3 性能要求

- 软件启动时间 < 3秒
- 界面切换响应时间 < 0.5秒
- 计时精确到秒
- 数据保存及时
- 内存占用 < 100MB
- CPU占用 < 5%（空闲时）

## 5. 数据管理需求

### 5.1 本地存储

- 使用SQLite数据库存储任务数据
- 数据文件存储在用户文档目录下
- 历史记录保留最近1年（可配置）
- 支持数据导出（JSON、CSV格式）
- 支持数据导入和恢复
- 定期自动备份（每日）

### 5.2 云同步（可选）

- 支持第三方云存储（如OneDrive、Google Drive）
- 加密后上传，保证数据安全
- 手动同步和自动同步选项
- 冲突处理策略（以最新为准或用户选择）

## 6. 辅助功能需求

### 6.1 提醒功能

- Windows原生通知提醒
- 任务开始提醒（可设置提前时间）
- 休息时间提醒
- 未完成任务每日定时提醒
- 声音提醒（可选自定义提示音）
- 闪烁任务栏图标提醒

### 6.2 帮助引导

- 首次启动的欢迎向导
- 工具提示和帮助信息
- 内置帮助文档（F1快捷键）
- 检查更新功能
- 关于页面显示版本信息

## 7. 非功能需求

### 7.1 可靠性

- 计时准确性保证
- 数据不丢失
- 异常处理机制

### 7.2 兼容性

- 支持Windows 10/11操作系统
- 支持不同屏幕分辨率和DPI缩放
- 适配暗色/浅色系统主题
- 支持多显示器环境

### 7.3 隐私保护

- 数据仅本地存储，不上传到服务器
- 不收集用户任何个人信息
- 开源代码，透明可审计
- 符合GDPR等隐私保护规范

- 推荐使用跨平台框架（如Electron、Tauri）

### 9.2 部署方式

- 提供安装包（.exe/.msi）
- 支持便携版（绿色版）
- 自动更新机制
- 数字签名认证
